活动V3为每条item固定六个引文槽、每条risk固定三个引文槽，仍验证完整清单、目录ID、UTF-16原始位置和有限同页owner关系。引用精确不代表结论正确；不完整关系保持未知，不能借用相邻产品或另一页面的正确内容。

发布策略先校验全部模型字段与风险，再用真实库存/执行边界说明替代未经核实的模型局限原文。状态经规则或证据策略调整时，全部可选风险暂缓并说明数量；可能有用的无关线索也会暂缓，不表示问题已解决。基准保留原答，在线保存报告没有承诺保留全部provider原文或暂缓风险对象。
