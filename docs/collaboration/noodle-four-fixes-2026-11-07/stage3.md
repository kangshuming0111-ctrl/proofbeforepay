## 修改前与门槛

纯文本段落已有支持，但同一菜品的 `strong/span` 段落和 `h3 + p.price` 菜单卡片常因无法定位完整对象而未知。复查还实际发现：普通纯文本价格若带 `display:none` 或 `opacity:0`，可绕过只在恢复分支应用的静态发布资格检查。

门槛是同一已约定文件／菜品／金额的完整对象能被精确核对，邻项、别页、隐藏内容或片段引文不能替代；所有价格正向路径执行统一资格检查，原始模型未知不提升。不能确认的结构／样式继续未知，不推断页面实际隐藏或交付失败。

## DeepSeek 与独立裁定

DOM 与发布计划分别有有界审查；DOM 首次格式无效，保留原件后仅作一次短格式修正。采纳普通额外 class token 的易用性意见，保留明确 `menu-item`／`price` token、完整两字段对象和隐藏 token 拒绝规则。关于无关段落可冒充价格、遗漏 HTML 不被发现的意见，用真实函数反例反证，不据此改写原有权威：完整正确价格可作控制，无关引文、只有无关正文／惰性模板价格、覆盖清单漏掉额外 HTML 均不获发布。

源码、有效后审、独立裁定和冻结哈希保存在本轮 `outputs/noodle-four-fixes-2026-11-07/` 记录中；界面来源链的单次有效后审和裁定为 `stage3-ui-adjudication.json`。后审是有限源码建议，不代替测试或证明模型准确率。

## 实现与实际验证

- 新增有限 v2 同对象读取器：闭合段落／列表项中的 text、span、strong，或明确菜单卡片中直接对应的 h3 与 p.price。完整原文引用、唯一菜名、币种及最小货币单位相符；不组合跨卡片、跨行或跨文件值。保留原 v1 的确定结论与脚本、重复菜名、合并选项等未知边界，只补原来无法定位复杂对象的一类情况。
- 新增有限 HTML/CSS 发布资格模块，正常路径与恢复路径共用；未知样式、隐藏或动态属性、非完整原始引用等继续待核。新增普通菜单 head、viewport、同站 CSS、导航与有限常规布局样式支持，不按某个样例的 CSS 字符串硬编码。
- 统一入口也检查完整 HTML/CSS 清单。根代理实际复现并修复了“CSS 已标截断，但正常无 marker 路径仍可肯定”的导出一致性缺口：补后同例不获肯定，完整来源控制仍通过。当前在线输入本来采用完整源码或拒绝超限；没有声称线上曾发送截断前缀。
- 新报告显式使用 `source-publication-v2`／`source-finding-v2`，同时必须有原文完整性政策。旧 schema1／旧缺省保持 v1；错配版本、删除新报告的完整性政策、把新事实回填旧未知、无 marker 正向绕过资格等均被拒绝。没有把一致性验证说成真实性签名。
- 八处现有界面来源判断支持明确的新旧版本，逐项、总览、主行动、计数和草稿不会把系统源码发布误称为 AI 自行判断。没有改变状态、数量、行动目标或写入门槛。

根代理独立核心测试 25/25、整合／导出／界面／严格回放 97/97 通过。首轮曾因合成历史 quote 缺少原有演示模式元数据而有一项失败，原日志保留；修正夹具构造后重新通过，没有修改 409 校验或旧 fixture。
