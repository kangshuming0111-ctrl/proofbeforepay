   新8场景共有9条要求，不能把“8个场景”和“9条要求”当作同一分母。
   已用于开发的电话反例须明确为已知场景；prospective预注册和后续原答应单独记录。
2. **自建动态参考站**有4种合成 profile；**新第三方项目**只有1个官方 Flask tutorial。
   修改适配器后的重跑仍是同一个已知项目，不算新增客户或盲测。
3. **源码引文精确**不意味着解释正确；模型判断、独立后台真实性和完整网站覆盖仍需要
   各自证据。邮件未适配、未运行、超时、原生不符不能从摘要里消失。
4. **真人首次使用**仍没有新结果。已有严格会话记录工具继续区分操作者、合成和真人，
   不以自动演练、AI审阅或空样本生成真人成功率。
5. **记录一致性、签名有效性、身份与实际执行**是不同结论。公开公钥和签名可以保留，
   私钥、运行环境秘密、SQLite、venv、cookies和临时账号状态不能进入公开包。
